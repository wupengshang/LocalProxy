# 轻量代理（原型）

一个 Chrome / Edge Manifest V3 浏览器扩展，用本机 Clash 等服务提供的 HTTP 或 SOCKS5 代理，按订阅或手动规则决定哪些网站走代理。扩展不提供代理服务，使用前请先启动 Clash。

## 安装

1. 打开浏览器的 `chrome://extensions`（Edge 为 `edge://extensions`），开启「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本目录 `local_proxy`。
3. 点击扩展图标，设置本机 Clash 的监听地址、端口和协议并保存。默认是 HTTP `127.0.0.1:7890`，请以 Clash 实际设置为准；各台电脑需要分别设置。
4. 在「规则订阅」中点击「更新订阅」。默认地址为 GFWList 的 GitHub 原始文件；如果网络无法访问，可以换成自己信任、能够访问的兼容订阅地址。
5. 选择「智能模式」，也可点击「添加当前网站」或输入域名。扩展管理页点击刷新可加载代码修改。

## 功能和规则

- 支持多个本机代理配置，一次选择一个；数据仅保存到当前浏览器的本地存储，不在电脑间同步。
- 工具栏图标上的绿色「智」、蓝色「全」、灰色「停」分别表示智能、全局、直连模式；红色「!」表示浏览器代理设置未被本扩展接管。标识表示设置状态，并不代表 Clash 连接已验证。
- 智能、全局、直连三种模式。直连模式仍由本扩展控制浏览器代理设置；停用或移除扩展可释放控制权。
- 智能模式中，手动域名及其子域名优先使用代理；然后检查订阅例外规则，再检查订阅代理规则；未命中则直连。localhost、127.0.0.1、::1 和 .local 域名始终直连。
- 订阅支持纯文本或 Base64 编码的常见 AutoProxy/GFWList 规则（域名锚点、通配符、分隔符、URL 锚点、正则和 `@@` 例外）。含 `$` 选项和页面元素过滤规则会跳过；并非完整 Adblock Plus 实现。更新成功后会保留上次规则，每 24 小时尝试更新；首次需要手动更新。浏览器未运行时不会执行定时任务。
- 订阅地址和规则可在本地修改。扩展需要读取活动标签页网址、访问订阅地址和设置代理；如果另一个扩展或企业策略控制代理，设置可能无法生效。
- Chrome 对 HTTPS 请求的 PAC URL 信息有限，路径规则可能不能按预期匹配；优先使用域名规则。此原型未实现 Firefox、代理认证、配置云同步和复杂规则语法。

## 检查

有 Node.js 时运行 `node tests/rules.test.js`。提供本地 GFWList 文件后可运行 `node tests/benchmark.js /path/to/gfwlist.txt`，比较优化前后的规则匹配；使用 Node.js 24+ 可运行 `node --disable-warning=ExperimentalWarning tests/compare-smartproxy.cjs /path/to/gfwlist.txt`，与相邻 SmartProxy 仓库的规则导入及核心匹配函数做样本对照。两项都是本地微基准，不代表浏览器实际加载速度。这是独立的轻量原型；旁边的 `SmartProxy` 目录是原始仓库，供参考。修改后重新加载扩展并在实际浏览器与本机 Clash 环境中测试。
